# Mini Bio
🎯 Mini Bio - Portfólio:  
Projeto desenvolvido com React e Next.js para apresentar informações pessoais de forma clara e objetiva.

## 🧠 Funcionalidades
- Exibe uma foto pessoal
- Mostra o nome do desenvolvedor
- Apresenta uma mini bio curta (2 a 3 frases)

## 🛠️ Tecnologias
- React
- Next.js
- CSS

## 🎯 Objetivo
Criar um site simples para apresentar informações pessoais de forma clara e objetiva, demonstrando habilidades básicas em React e Next.js e transmitindo profissionalismo e personalidade.
